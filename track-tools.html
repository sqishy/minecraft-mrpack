Track Tools RALLY

A ridden mount holding a shovel or pickaxe reshapes the ground beneath it as it moves, letting a race course be laid out by riding the route.

Overview

When a mount is ridden while its held item is a shovel or a pickaxe, it alters the ground along its path, carving a line centred on the mount. The effect applies both in free-roam and during a race. The travel path is sampled at sub-block steps, so a fast-moving mount carves a continuous line with no gaps.

Shovel

A held shovel flattens soil along the line into dirt path and removes low vegetation above the surface.

  • Affected soil: grass block, dirt, podzol, coarse dirt, mycelium, and rooted dirt.
  • Vegetation such as short grass, ferns, flowers, and saplings sitting on the surface is cleared and dropped as items.

Pickaxe

A held pickaxe paves the surface line with the block held in the rider's off hand, drawn from the rider's inventory. One block is consumed per surface block placed.

  • Any placeable block works — stone bricks, concrete, wool, and so on.
  • The pickaxe has no effect if the off hand is empty, holds a non-placeable item, or the rider has none of the off-hand block remaining. In Creative mode no blocks are consumed.
  • Surface blocks that already match the off-hand block are left unchanged.

Carve width

Both tools carve a line whose width is set by the tool's material tier. The width is always odd, so the mount travels down the centre of the line.

Tools of a modded or otherwise unrecognised tier fall back to the configured default width.

Configuration

Track Tools are enabled by default and controlled by the Rally server config:

  • mountTerraformEnabled — enables or disables the feature entirely.
  • mountTerraformWidth — fallback carve width for modded or unknown tool tiers. Even values are rounded down to the next odd number.
