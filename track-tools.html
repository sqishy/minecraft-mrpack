Track Tools RALLY

A ridden mount reshapes the world as it moves, according to the tool it holds — clearing, surfacing, felling, levelling and bridging, so a race course is laid out by riding the route.

Overview

Give a mount a tool as its held item and it works the ground as you ride, along a line centred on the mount. Between them the six tools will clear a route, surface it, cut it through a forest, level its gradient and carry it over a ravine — you drive the line you want and it appears behind you. The travel path is sampled at sub-block steps, so even a fast mount leaves a continuous line with no gaps.

Track Tools are free-roam only. Every tool is inert during a race — a track is something you build beforehand, not something you regrade under yourself mid-lap.

Blocks are placed without limit — you hold one as a template, not a stack as a supply — but only ground materials qualify. See Materials below.

Shovel

A held shovel flattens soil along the line into dirt path and removes low vegetation above the surface.

  • Affected soil: grass block, dirt, podzol, coarse dirt, mycelium, and rooted dirt.
  • Vegetation such as short grass, ferns, flowers, and saplings sitting on the surface is cleared and dropped as items.

Pickaxe

A held pickaxe paves the surface line with the block held in the rider's off hand. You need only one of that block — it is a template, not a supply. See Materials below.

  • The pickaxe has no effect if the off hand is empty or holds something that is not a track surface material.
  • Surface blocks that already match the off-hand block are left unchanged, so re-riding a line you have already paved costs nothing and changes nothing.
  • The pickaxe re-surfaces ground that is already there. To carry the line over a hole, use the bridge instead.

Materials

Track building does not consume blocks. Hand-hauling 8,500 blocks for a 5×1700 course is not the interesting part of designing one, so the paver, the grader and the bridge all place without limit from a single block held as a template.

What keeps that from being a duplication exploit is what they will place. The tools accept only blocks that already have a terrain category — the ground materials the race physics knows how to drive on:

  • Grass, dirt, coarse dirt, podzol, mycelium, rooted dirt, dirt path, farmland
  • Stone, cobblestone, andesite, granite, diorite, tuff, calcite, deepslate and blackstone
  • The brick and polished families — stone bricks, smooth stone, quartz, sandstone, purpur, nether brick, end stone brick, prismarine brick
  • Sand, red sand, gravel, clay, mud, snow, ice, magma, netherrack, nylium, soul sand, sculk, moss

Everything valuable is excluded by that rule rather than by a blocklist. In particular the effect blocks — gold, redstone, copper, emerald, lapis, amethyst, honey, slime, prismarine and crying obsidian — are not terrain, so an unlimited paver can never print them. Neither can it print ores, diamonds, or any build block that was never given driving characteristics.

Hold something off the list and the tool tells you so in the action bar instead of silently doing nothing.

Axe

A held axe cuts a rider-height corridor through everything growing in the way, and fells what it cuts. Riding a route through woodland clears it.

  • Cuts logs, leaves, bushes, saplings, bamboo, sugar cane, cactus, vines, mushroom blocks and nether wart blocks. Everything drops, so a run through a forest is also a timber harvest.
  • When it cuts through a trunk it fells the logs above the corridor too, so no stump is left hanging in mid-air. The orphaned canopy then decays on its own.
  • Built blocks are never touched — planks, chests, barrels and doors are all safe to ride past. Only living growth is on the list.
  • Clear-cutting is deliberately slow. See Ploughing below.

Shears

Shears cut the same corridor minus the logs: undergrowth, leaves and vines go, trunks stay. It trims a lane through a wood that remains a wood — for when you want the trees as scenery rather than gone.

  • Trunks are left standing, so you still have to steer around them.
  • Foliage is light work: shears get double the per-tick budget, and they are only slowed by the growth they can actually cut (a trunk they will never fell does not brake them).

Hoe — the grader

The other tools work the surface; the hoe works the gradient. It holds a smoothed running average of the mount's own height as a grade line, then cuts away anything standing above that line and fills in anything missing below it. Because the line lags the terrain, crests sit above it and dips below it — so driving a lumpy route turns it into a rideable slope.

  • Fill material comes from the block in your off hand and is unlimited, like the paver. With an empty off hand — or one holding something that is not a surface material — the hoe still grades, it just cuts high ground and cannot fill low ground.
  • Cuts up to 4 blocks above the line and fills up to 4 below it per column, both configurable.
  • Bedrock and fluids are left alone.
  • How hard it grades is set by mountGradeSmoothingSeconds: larger values flatten harder and ignore the terrain underneath, smaller values hug the ground and only shave the sharpest bumps.

Bridging

Give the mount a plain block instead of a tool — no off hand needed — and it decks gaps with that block as you ride: ravines, water, lava. It fills only gaps and never replaces ground that is already there, so you can carry a natural line across an obstacle without repaving the terrain either side of it.

  • The deck holds the height of the last solid ground the mount stood on, so a span runs level out across the gap instead of sloping down into it.
  • It is laid slightly ahead of the mount, so the deck is already there when you arrive — you ride straight out over the drop rather than falling and catching yourself.
  • The mount's block is a template and the deck is unlimited, so a single block bridges any span. It must be a surface material like everything else — see Materials above.
  • Because giving the mount a block is the whole trigger, take it back off when you are done or it will keep decking any gap you ride across.
  • Default deck width is 5, set by mountBridgeWidth.

Ploughing

Cutting through growth is not a free sprint. A mount holding an axe or shears is slowed in proportion to how much growth stands directly ahead of it — full speed in the open, down to 15% head-on into solid wood. You plough into a forest at a march and pick speed back up as the corridor opens.

  • A lone trunk or a screen of leaves barely registers; a dense wall of jungle is what really stops you.
  • A tool is only slowed by what it can remove, so shears ignore trunks entirely.
  • The tools also have a per-tick block budget scaled to their material tier, from 3 blocks (wood) to 16 (netherite), so a better axe genuinely clears faster.

Carve width

The tools carve a line whose width is set by the tool's material tier. The width is always odd, so the mount travels down the centre of the line.

Configuration

Track Tools are enabled by default and controlled by the Rally server config:

  • mountTerraformEnabled — enables or disables the whole feature.
  • mountTerraformWidth — fallback carve width for modded or unknown tool tiers, and the width shears trim. Even values are rounded down to the next odd number.
  • mountClearHeight — how tall the corridor an axe or shears cuts is (default 3, rider height).
  • mountAxeFellTrunks — whether an axe fells the trunk above its cut. Shears never fell trunks regardless.
  • mountClearSlowdown — maximum ploughing speed penalty (default 0.85). Set to 0 to clear-cut at full speed.
  • mountBlocksPerTick — fallback per-tick block budget for the block-hungry tools on unrecognised tiers.
  • mountGradeMaxCut / mountGradeMaxFill — how far above and below the grade line the hoe will work, per column.
  • mountGradeSmoothingSeconds — how aggressively the hoe grades.
  • mountBridgeWidth — deck width when bridging a gap.
